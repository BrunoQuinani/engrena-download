Android (celular)

Baixar app para Android (.apk)

  1. Abra este link no celular e baixe o arquivo .apk.
  2. Ao abrir, o Android pede para permitir a instalação de “fontes desconhecidas” para o navegador: autorize só para este app.
  3. Toque em Instalar e entre com o mesmo e-mail e senha do computador.

Versão de campo: ordens, confirmação de execução, horas, material, eventos e alertas. Para atualizar, use “Mais → Verificar atualização” no app.

Como instalar no Windows

  1. Baixe e abra o SIMAP-Setup.exe. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo.
  2. Avance no assistente. Não é preciso ser administrador: o SIMAP é instalado só para o seu usuário, com atalho na Área de Trabalho e no menu Iniciar.
  3. Para desinstalar: Configurações do Windows → Aplicativos → SIMAP → Desinstalar (ou “Desinstalar SIMAP” no menu Iniciar).
  4. Entre com seu e-mail e senha. No primeiro acesso, use “solicitar acesso” e aguarde um gerente aprovar.

Depois de instalado, o app se atualiza sozinho: ao abrir, ele avisa quando há versão nova.
